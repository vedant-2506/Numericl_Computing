# 1. 📁 `Complex/` Directory (Complex Number Engine)

### **File: `Complex/Complex.hpp`**
* **Purpose**: Defines the `Complex` class representing complex numbers ($z = a + bi$).
* **Mathematical Concept**: Complex algebra in standard Cartesian form $a + bi$.
* **Connections**: Included by `Complex/Complex.cpp` and `Complex/main.cpp`.
* **Functions & Members**:
  * `float real, img`: Public member variables storing real ($a$) and imaginary ($b$) parts.
  * `Complex()`: Default constructor to initialize an empty object.
  * `Complex(float r, float i)`: Parameterized constructor for setting $a$ and $b$.
  * `Complex add(Complex &c)`: Calculates $z_1 + z_2 = (a_1 + a_2) + (b_1 + b_2)i$.
  * `Complex subtract(Complex &c)`: Calculates $z_1 - z_2 = (a_1 - a_2) + (b_1 - b_2)i$.
  * `Complex multiply(Complex &c)`: Calculates $z_1 \cdot z_2 = (a_1 a_2 - b_1 b_2) + (a_1 b_2 + a_2 b_1)i$.
  * `Complex divide(Complex &c)`: Calculates $\frac{z_1}{z_2} = \frac{(a_1 a_2 + b_1 b_2) + (b_1 a_2 - a_1 b_2)i}{a_2^2 + b_2^2}$.
  * `Complex conjugate()`: Calculates $\bar{z} = a - bi$.
  * `float norm()`: Calculates modulus $|z| = \sqrt{a^2 + b^2}$.

# 2. 📁 `RootFinding/` Directory (Non-Linear Equations)

### **File: `RootFinding/Include/Root.hpp`**
* **Purpose**: Header declaring the `RootFinder` polymorphic base class and three derived root-finding algorithms.
* **Connections**: Included by `RootFinding/Src/Root.cpp` and `RootFinding/main.cpp`.
* **Classes & Functions**:
  * `class RootFinder`: Abstract base class.
    * `double tol`: Tolerance for convergence criterion ($|x_{k+1} - x_k| < \text{tol}$).
    * `virtual double f(double x)`: Defines target function $f(x)=0$.
    * `virtual double solve() = 0`: Pure virtual function overridden by each solver.
  * `class Bisection : public RootFinder`:
    * `bool findInterval()`: Scans intervals $[-5, 5]$ with step $0.05$ to find $[a, b]$ where $f(a)\cdot f(b) < 0$ (Bolzano's Theorem).
    * `double solve()`: Implements Bisection method.
  * `class NewtonRaphson : public RootFinder`:
    * `double df(double x)`: Evaluates the derivative $f'(x)$.
    * `double solve()`: Solves using tangent iteration $x_{k+1} = x_k - \frac{f(x_k)}{f'(x_k)}$.
  * `class FixedPoint : public RootFinder`:
    * `double g(double x)`: Rearranged iteration function $x = g(x)$.
    * `double solve()`: Solves using fixed-point iteration $x_{k+1} = g(x_k)$.

---

### **File: `RootFinding/Src/Root.cpp`**
* **Purpose**: Implements algorithms for bracket finding, Bisection, Newton-Raphson, and Fixed Point iteration.
* **Mathematical Methods**:
  * **Bisection**: Repeatedly halves interval $[a, b]$ where $m = \frac{a+b}{2}$. Halves error bound each step: $O(\log_2(\frac{b-a}{\text{tol}}))$.
  * **Newton-Raphson**: Quadratic convergence algorithm using tangent line intersections.
  * **Fixed-Point Iteration**: Solves $g(x) = x$, guaranteed to converge when $|g'(x)| < 1$.
* **Connections**: Includes `Root.hpp`, `<iostream>`, `<cmath>`, and `<iomanip>`.

---

### **File: `RootFinding/main.cpp`**
* **Purpose**: Console entry point allowing users to choose a root-finding algorithm.
* **Connections**: Includes `Include/Root.hpp`.
* **Workflow**: Uses base class pointer polymorphism (`RootFinder* solver`) to instantiate `Bisection`, `NewtonRaphson`, or `FixedPoint`, calls `solver->solve()`, outputs the root, and deletes memory.

  * **Diagonal Dominance Transformation**: Swaps rows to satisfy $|a_{ii}| \ge \sum_{j \neq i} |a_{ij}|$.
* **Connections**: Includes `Matrix.hpp`, `<cmath>`, `<stdexcept>`.

## 4.2 Matrix Operations & Linear System Solvers

### **File: `Matrix/Include/BasicOperation.hpp` & `Matrix/Src/BasicOperation.cpp`**
* **Purpose**: Class derived from `Matrix` for standard linear algebra tasks (Matrix Addition, Subtraction, Multiplication, Scalar Operations, Transposition, Determinant).
* **Connections**: Includes `BasicOperation.hpp`, `Matrix.hpp`.

---

### **File: `Matrix/Include/LinearOperation.hpp` & `Matrix/Src/LinearOperation.cpp`**
* **Purpose**: Base class for linear system solvers ($Ax = b$).
* **Key Function**: `generateAugmentedMatrixFile(leftFile, rightFile, outputFile)` reads coefficient matrix $A$ and constant vector $b$, creating augmented matrix file $[A | b]$.
* **Connections**: Includes `LinearOperation.hpp`, `Matrix.hpp`.

---

### **File: `Matrix/Include/GaussianElimination.hpp` & `Matrix/Src/GaussianElimination.cpp`**
* **Purpose**: Direct solver for system $Ax = b$ using Gaussian Elimination.
* **Methods**:
  * `gaussianWithPivoting(...)`: Performs partial pivoting (swapping rows for largest column pivot $|a_{ik}|$) to maintain numerical stability and eliminate divide-by-zero errors.
  * `gaussianWithoutPivoting(...)`: Standard forward elimination into upper triangular matrix followed by back-substitution.
* **Connections**: Includes `GaussianElimination.hpp`, `PlotHelper.hpp`, `Solutionprinter.hpp`.

---

### **File: `Matrix/Include/LUDecomposition.hpp` & Implementation Files (`DoolittleLU.cpp`, `CroutLU.cpp`, `Cholesky.cpp`)**
* **Purpose**: Solves $Ax = b$ by decomposing $A$ into lower ($L$) and upper ($U$) triangular matrices.
* **Methods**:
  1. **Doolittle LU** (`DoolittleLU.cpp`): $A = LU$ where $L$ has 1s on main diagonal ($l_{ii} = 1$). Solves $Ly = b$ then $Ux = y$.
  2. **Crout LU** (`CroutLU.cpp`): $A = LU$ where $U$ has 1s on main diagonal ($u_{ii} = 1$). Solves $Ly = b$ then $Ux = y$.
  3. **Cholesky Decomposition** (`Cholesky.cpp`): Decomposes symmetric positive-definite matrix $A = L L^T$ where $l_{ii} = \sqrt{a_{ii} - \sum_{k=0}^{i-1} l_{ik}^2}$.
* **Connections**: Includes `LUDecomposition.hpp`, `PlotHelper.hpp`, `Solutionprinter.hpp`.

---

### **File: `Matrix/Include/Iterativemethod.hpp` & `Matrix/Src/Iterativemethod.cpp`**
* **Purpose**: Solves $Ax = b$ using iterative numerical methods.
* **Methods**:
  1. **Gauss-Jacobi Iteration**: Solves $x_i^{(k+1)} = \frac{1}{a_{ii}} \left( b_i - \sum_{j \neq i} a_{ij} x_j^{(k)} \right)$ using values from previous iteration.
  2. **Gauss-Seidel Iteration**: Solves $x_i^{(k+1)} = \frac{1}{a_{ii}} \left( b_i - \sum_{j < i} a_{ij} x_j^{(k+1)} - \sum_{j > i} a_{ij} x_j^{(k)} \right)$ using updated values immediately for faster convergence.
* **Feature**: Automatically checks diagonal dominance and attempts row reordering if matrix is not dominant.
* **Connections**: Includes `Iterativemethod.hpp`, `PlotHelper.hpp`, `Solutionprinter.hpp`.

## 4.3 Eigenvalues & Curve Fitting

### **File: `Matrix/Include/Eigenvalue.hpp` & `Matrix/Src/Eigenvalue.cpp`**
* **Purpose**: Bounds real/complex eigenvalues of square matrices.
* **Math Concept**: **Gerschgorin Circle Theorem**. Every eigenvalue $\lambda$ of matrix $A$ lies within at least one Gerschgorin disc $D(a_{ii}, R_i)$ in the complex plane, where center is $a_{ii}$ and radius is $R_i = \sum_{j \neq i} |a_{ij}|$.
* **Connections**: Includes `Eigenvalue.hpp`, `Matrix.hpp`, system Gnuplot calls.

### **File: `Matrix/Include/LeastSquare.hpp` & `Matrix/Src/LeastSquare.cpp`**
* **Purpose**: Fits polynomial $f(x) = a_0 + a_1 x + a_2 x^2 + \dots + a_m x^m$ to $n$ data points using Method of Least Squares.
* **Math Concept**: Minimizes Residual Sum of Squares (RSS): $\min \sum (y_i - f(x_i))^2$. Solves Normal Equations $(X^T X) c = X^T y$ where $X$ is Vandermonde matrix. Computes RSS, MSE, RMSE.
* **Connections**: Includes `LeastSquare.hpp`, `CurveFitting.hpp`.

# 🎯 KEY ADVANTAGES & DESIGN HIGHLIGHTS

1. **Object-Oriented Architecture**: Clean inheritance hierarchy with `Matrix` acting as standard data container and operation handler.
2. **Numerical Stability**: Includes partial pivoting in Gaussian Elimination and normal equation solving, and checks diagonal dominance for iterative convergence.
3. **Automated Visualization**: Direct integration with Gnuplot to generate PNG graph visualizations.
4. **Detailed Logging**: Algorithms write step-by-step intermediate matrices, basis polynomials, and residual metrics to output files.
